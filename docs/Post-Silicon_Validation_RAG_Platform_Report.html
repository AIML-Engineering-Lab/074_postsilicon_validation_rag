1   Overview

Objective: Build a 100% locally-deployed RAG system that enables post-silicon validation engineers to query validation logs, test reports, and technical documentation using natural language, with <5s response time and source citations.

Domain: Semiconductor Post-Silicon Validation — Knowledge Management

Key Innovation: Fully local deployment with Ollama Llama2 (zero API costs) + instructor-large domain-specific embeddings + ChromaDB vector storage. Supports 7 document formats with source citation for every answer.

4   Key Learnings
  • 100% local deployment is non-negotiable for semiconductor companies — validation logs contain proprietary process data that cannot leave the network.
  • instructor-large embeddings outperform generic embeddings (e.g., all-MiniLM) on technical semiconductor content because they handle domain acronyms and jargon.
  • Source citations build engineer trust — showing which document chunk the answer came from lets them verify and correct the AI.
  • 7 document formats (.txt, .log, .report, .csv, .xlsx, .pdf, .docx) cover 99% of what validation engineers actually use.
  • Ollama Llama2 on a 32GB Mac achieves <5s responses — good enough for interactive use, no GPU cluster needed.
  • Conversation history export (Markdown/JSON) creates shareable investigation trails — critical for cross-team debugging sessions.
